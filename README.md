# 📊 Analyse des Performances Étudiantes 🎓

Ce projet a pour objectif d’analyser les **facteurs influençant la performance académique des étudiants** à partir de leurs habitudes d’étude et de variables comportementales.  
Il s’appuie sur une démarche complète d’**analyse de données**, allant du nettoyage des données à l’analyse multivariée, afin d’identifier les éléments clés de la réussite académique.

---

## 🎯 Objectifs du Projet

- Comprendre l’impact des habitudes d’étude sur les résultats académiques  
- Identifier les variables les plus influentes sur la performance des étudiants  
- Appliquer des méthodes statistiques et exploratoires  
- Extraire des insights utiles pour l’aide à la décision  

---

## 📂 Démarche d’Analyse

Le projet suit une **approche structurée en quatre étapes principales** :

### 1️⃣ Préparation et Nettoyage des Données
- Traitement des valeurs manquantes  
- Suppression des doublons  
- Correction des types de variables  
- Renommage des colonnes pour une meilleure lisibilité  

📌 **Résultat :**  
Un jeu de données propre, cohérent et prêt pour l’analyse.

---

### 2️⃣ Analyse Univariée
- Statistiques descriptives (moyenne, médiane, variance, écart-type)  
- Analyse des distributions  
- Visualisations (histogrammes, boxplots)  

🎯 Objectif : comprendre le comportement général des étudiants.

---

### 3️⃣ Analyse Bivariée
- Étude des relations entre deux variables  
- Analyses de corrélation  
- Tests statistiques (corrélation de Pearson, ANOVA)  
- Visualisations comparatives (scatter plots, boxplots)  

📌 Exemple :  
Influence du **temps d’étude** et du **sommeil** sur la **performance académique**.

---

### 4️⃣ Analyse Multivariée
- Analyse globale des interactions entre toutes les variables  
- Application de l’Analyse en Composantes Principales (ACP / PCA)  

📊 **Résultats clés :**
- Réduction de la dimensionnalité  
- Identification des axes principaux expliquant la variance  
- Mise en évidence de profils d’étudiants distincts  

---

## 📊 Données

- **Source :** `student_habits_performance.csv`  
- **Type :** Données éducatives et comportementales  

### Variables principales :
- Habitudes d’étude  
- Facteurs personnels (sommeil, stress, régularité)  
- Environnement d’apprentissage  
- **Performance académique** (variable cible)

---

## 🛠️ Technologies Utilisées

Le projet est réalisé en **Python** avec les bibliothèques suivantes :

- Pandas & NumPy – manipulation et nettoyage des données  
- Matplotlib & Seaborn – visualisation des données  
- Scikit-learn – analyse multivariée (ACP / PCA)  
- SciPy – analyses statistiques  

---

## 📌 Résultats et Perspectives

- Identification des facteurs clés de réussite académique  
- Compréhension des relations entre habitudes et performance  
- Base solide pour des travaux futurs en **Machine Learning** et prédiction des résultats académiques
